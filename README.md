# Sohyeon Kim — academic website

Static site (no build step). Open `index.html` in a browser to preview.

## Publish on GitHub Pages
1. Create a public repo named `<your-github-username>.github.io`.
2. Upload everything in this folder (including `assets/` and `.nojekyll`).
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Your site appears at `https://<your-github-username>.github.io` within a few minutes.

## Updating
- Text lives in `index.html` (sections: About, Research, Teaching, CV).
- Replace `assets/Kim_CV.pdf` when your CV changes.
